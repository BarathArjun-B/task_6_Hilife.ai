Work Timer Web App

This project is a responsive Work Timer Application developed using:

- HTML5
- CSS3
- Vanilla JavaScript
- LocalStorage

The timer is designed for:
- studying
- productivity tracking
- office/work management style timing

The application maintains timer state even after:
- page refresh
- tab switching
- browser minimize
- reopening browser

---

# Features

- Start Timer
- Pause Timer
- Resume Timer
- Reset Timer
- Millisecond Support
- Persistent Timer State
- Session Status Display
- Responsive Dashboard UI
- LocalStorage Data Persistence
